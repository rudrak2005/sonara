# SONORA

SONORA — The AI Retro Music Machine

## Project

SONORA is an AI-native music experience that learns what a user likes, when they listen, and how their listening context evolves.

## Architecture

- Web: Next.js + React + TypeScript
- API: NestJS + TypeScript
- Database: PostgreSQL + Prisma
- Cache: Redis
- AI: Provider abstraction
- Testing: Vitest/Jest + Playwright
- CI/CD: GitHub Actions
